## Privacy Policy

### What Actually Happens

Your typed amount and chosen currency never leave your device. This is not merely a promise — it's a commitment written into FX Convert's code. 🐾

The website downloads current rates when the page loads, and again whenever you tap 'Update Rates'. Each download is one request to a public currency rate server — open.er-api.com, or api.frankfurter.dev (if the primary one is down). One of these servers replies with today's currency rates. Done.

FX Convert does not:
- Save or remember your numbers
- Use cookies or analytics

It doesn't track you. It doesn't store you. It doesn't know you. Then again, it's a cat — it was never really paying attention to you anyway.

Everything you type lives only in your browser's memory. Close the tab and it's gone, just like a cat the moment you want it on your lap.

### An Honest ~~Pawnote~~ Footnote

Only three parties are involved in serving this website:

| Who | What they see |
|-----|---------------|
| **GitHub** (hosts this page) | Your IP address, logged for security — as any web host does |
| **The currency rate servers** (`open.er-api.com`, `api.frankfurter.dev`) | Your IP address, as with any web request — and the same fixed currency rate request every visitor sends; nothing personal in it |
| **Your device** | Everything you type. The maths happens right there, locally — for your eyes only |

## Credits & Catnip

This cat doesn't hunt its own rates. Fresh figures come from two public servers, summoned the moment you ask:

- [Exchange Rate API](https://www.exchangerate-api.com) — the primary bowl. Daily rates, free for non-commercial use with attribution.
- [Frankfurter](https://frankfurter.dev) — the backup bowl. Open source, powered by European Central Bank reference rates.

Both run on kindness, open data, and zero API keys.
